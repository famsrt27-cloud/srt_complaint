# อัพเดทแก้ไขข้อมูลเว็บไซต์ร้องเรียนการรถไฟแห่งประเทศไทย

> แปลงจากไฟล์ PDF: `อัพเดทแก้ไข(ครั้งที่1_2569_21.09.69).pdf`

## วิธีอ่านเอกสารนี้ด้วย Codex CLI

ข้อความด้านล่างเป็นข้อความที่ดึงจาก PDF ส่วนรายละเอียดที่เป็นภาพให้เปิดไฟล์ภาพที่ลิงก์ไว้ในแต่ละหน้า โดยเฉพาะภาพหน้าต้นฉบับใน `pages/` ซึ่งคงตำแหน่งและบริบทของเอกสารไว้ครบถ้วน หากต้องการให้ Codex วิเคราะห์ UI หรือข้อความในภาพ ให้ระบุไฟล์ภาพที่ต้องดูอย่างชัดเจน เช่น `pages/page-2.png` หรือ `images/image-006.jpg`.

## ข้อความจากเอกสาร

อัพเดทแก้ไขข้อมูลเว็บไซต์ร้องเรียนการรถไฟแห่งประเทศไทย
ครั้งที่ 1/2569 วันที่ 21 กันยายน 2569

1. เพิ่มปุ่มและคำให้เช็คถูก ในช่องที่ผู้ร้องกรอกข้อมูลเพื่อที่จะร้องเรียน ก่อนที่จะส่งเรื่องร้องเรียน
กรณียินยอมให้ข้อมูล มีช่องคำว่า : ผู้ร้องยินดีเปิดเผยชื่อ-นามสกุล และหมายเลขโทรศัพท์
เพื่อให้เจ้าหน้าที่ติดต่อกลับ
กรณีไม่ยินยอม มีช่องคำว่า : ผู้ร้องประสงค์ให้ปกปิด ชื่อ-นามสกุล และหมายเลขโทรศัพท์

2. บังคับกรอกข้อมูลทุกช่อง เพื่อที่จะนำมาเป็นข้อมูลที่ให้ฝ่ายที่เกี่ยวข้องพิจารณาต่อได้

3. มีให้ผู้ร้องตรวจทาน/ทบทวน ข้อมูลทั้งหมดอีกครั้ง ก่อนกดส่งยื่นเรื่อง

---

4. รูปโปรไฟล์เป็นไอค่อนอื่น

5. อัพเดทแบบฟอร์มเรื่องร้องเรียน : ข้อมูลติดต่อ

6. อัพเดทแบบฟอร์มเรื่องร้องเรียน : ตัดข้อมูลส่วนนี้ออก

---

7. อัพเดทแบบฟอร์มเรื่องร้องเรียน : ตัดข้อมูลส่วนนี้ออก

8. อัพเดทแบบฟอร์มเรื่องร้องเรียน : หากระบบต้องมีวันที่พิมพ์ ก็ให้อยู่ท้ายกระดาษ ฟอนต์เล็กที่สุด
9. ตัวอย่างแบบฟอร์มเรื่องร้องเรียน (ระบบร้องเรียนของ 1690 ที่ประชาสัมพันธ์ใช้อยู่ในปัจจุบัน)

---

10. แบบฟอร์มเรื่องร้องเรียน (ระบบใหม่) เพิ่มรายละเอียด ดังนี้

11. แบบฟอร์มเรื่องร้องเรียน (ระบบใหม่) : เพิ่มรายละเอียด โดยเพิ่มปุ่มและคำให้เช็คถูก ดังนี้

---

12. แบบฟอร์มเรื่องร้องเรียน (ระบบใหม่) : เพิ่มรายละเอียด โดยเพิ่มประโยค เป็นคำว่า “โปรดพิจารณา
ดำเนินการในส่วนที่เกี่ยวข้อง และขอความกรุณาแจ้งตอบกลับศูนย์ประชาสัมพันธ์ เพื่อตอบชี้แจงผู้
ร้องทราบต่อไปด้วย จักเป็นพระคุณยิ่ง”

13. แบบฟอร์มเรื่องร้องเรียน (ระบบใหม่) : เพิ่มรายละเอียด โดยเพิ่มลายเซ็น กปส. ชื่อ ตำแหน่ง ดังนี้
และปรับขนาดลายเซ็นตามความเหมาะสม

14. ท้ายกระดาษ เพิ่มรายละเอียด ประมาณนี้
