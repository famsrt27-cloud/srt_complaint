# วิธีใช้งานชุดไฟล์นี้กับ Codex CLI

1. แตกไฟล์ชุดนี้ไว้ในโฟลเดอร์โปรเจกต์
2. เปิด `document.md` เป็นเอกสารหลัก
3. รูปที่ Codex ต้องอ่านต้องอยู่ในโฟลเดอร์เดียวกับ Markdown ตามโครงสร้างเดิม (`pages/` และ `images/`)
4. ใน prompt ให้ระบุเส้นทางไฟล์ภาพ เช่น:

```text
อ่าน document.md และตรวจสอบภาพ pages/page-2.png, pages/page-3.png
สรุป requirement ของแบบฟอร์มใหม่ โดยห้ามเดาข้อความที่อ่านจากภาพไม่ชัด
```

5. ถ้าจะย้ายไฟล์ ให้ย้ายทั้งโฟลเดอร์ ไม่ใช่เฉพาะ document.md เพราะลิงก์รูปเป็น relative path

`pages/page-*.png` เหมาะสำหรับดูภาพรวมและตำแหน่งองค์ประกอบของแต่ละหน้า ส่วน `images/image-*.jpg/png` เหมาะสำหรับวิเคราะห์รูปที่ฝังอยู่แบบเฉพาะเจาะจง
